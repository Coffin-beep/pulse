# Pulse 💜

Мессенджер в приятной тёмно-фиолетовой теме. Работает на **чистом Node.js без единой зависимости** — ничего устанавливать не нужно, только Node.js 16+.

## Быстрый старт

```bash
node server.js        # или: npm start
```

Открой в браузере: **http://localhost:3000**

Другой порт:

```bash
PORT=8080 node server.js
```

Все данные (пользователи, чаты, голосовые) хранятся локально в папке `./data` — можно удалить её, чтобы начать с чистого листа.

## Возможности

- **Регистрация** — Username (уникальный, через `@`), Nickname, **обязательная почта** и пароль (scrypt-хеш)
- **Личные чаты** — текстовые сообщения, статусы «прочитано» ✓✓, онлайн-присутствие
- **Голосовые сообщения** — запись с микрофона, автоматическая волновая форма, встроенный плеер с перемоткой по клику на волну
- **Группы и каналы** — создаёт любой пользователь; каналы со стилем «только админы публикуют», группы — общий чат; приватные и публичные
- **Обзор сообществ** — поиск публичных групп и каналов, вступление в один клик
- **Управление участниками** — добавление/удаление, роли (владелец/админ), передача владения при выходе
- **Живые обновления** — Server-Sent Events: сообщения, онлайн-статусы и изменения чатов приходят мгновенно (плюс резервный опрос)
- **Адаптивный дизайн** — от телефона до десктопа

## Как протестировать переписку

Открой `http://localhost:3000` в двух разных окнах браузера (или в обычном + приватном режиме), зарегистрируй двух пользователей и найди друг друга через поиск по `@username`.

## Архитектура

```
server.js            — точка входа (HTTP-сервер)
src/
  api.js             — REST API + SSE (события, присутствие)
  storage.js         — хранение: JSON-файлы + аудиофайлы в ./data
  static.js          — раздача статики из public/
  http-utils.js      — парсинг тел запросов, ответы, ошибки
public/
  index.html         — каркас приложения
  css/app.css        — тёмно-фиолетовая тема
  js/app.js          — вся логика интерфейса
  js/api.js          — fetch-клиент + SSE-подключение
  js/ui.js           — DOM-хелперы, иконки, аватары, модалки
  js/audio.js        — запись голосовых, волновая форма, плеер
```

### API (кратко)

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/auth/register` | регистрация (username, nickname, email, password) |
| POST | `/api/auth/login` | вход (email или @username) |
| GET/POST | `/api/chats` | список / создание (диалог, группа, канал) |
| GET/PATCH/DELETE | `/api/chats/:id` | детали / настройки / удаление |
| GET/POST | `/api/chats/:id/messages` | история (с `?after=`) / отправка текста |
| POST | `/api/chats/:id/voice` | отправка голосового (binary + duration/peaks) |
| POST | `/api/chats/:id/join` / `leave` / `read` | вступление / выход / прочитано |
| GET | `/api/discover` | публичные группы и каналы |
| GET | `/api/events` | SSE-поток событий |
